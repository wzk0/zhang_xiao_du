编码检测与转换工具

选择 .txt 文件后，这里会显示编码检测结果。

    
选择文件后，本页先读取字节：能用 UTF-8 严格解码就按 UTF-8 上传；否则按 GBK 解码、重新编码为 UTF-8 后再上传，同时去掉 BOM、把 CRLF 统一为 LF。

    设备热点下没有外网，跳转到外部网站会打不开，所以本页就是那个「能转编码的网页」；检测到非 UTF-8 时会自动带你到这里并高亮，转换零操作、无需手动另存。

    万一浏览器不支持自动转换，请在电脑上用记事本或 VS Code 打开 txt，选「另存为 UTF-8」后再上传。设备端仍按收到的字节原样保存，不会去水印、去段首缩进或改动正文。
